# Continuing the Journey

If you arrived here expecting a conventional number system, you may be surprised.

If you arrived expecting a finished mathematical theory, you may also be surprised.

**LaTecimalSystem is neither a replacement for decimal mathematics nor a claim that existing mathematics is wrong.**

Instead, it is an exploration.

A language of orientation.
A language of movement.
A language of rank, scale, direction, and relationship.

Where conventional mathematics often asks:

> "What is the value?"

LaTecimal frequently asks:

> "In which direction does the value exist?"

or

> "At which rank of observation does the value become visible?"
